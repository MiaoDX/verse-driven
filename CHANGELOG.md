# Changelog

## v0.1.0 - 2026-05-03

Initial release of Verse-Driven Development.

- Ships the `scripture-mcp` Go binary with stdio MCP, CLI lookup, prompt-hook lookup, recap, and init commands.
- Bundles KJV, 道德经, and 心经 packs with SHA-256 integrity metadata.
- Adds Claude Code and Codex adapters for one-turn Mode A injection.
- Adds terminal-only Mode B recap, including optional first-letter masking and SM-2 style learning mode.
- Adds lifecycle and coding-quality benchmark gates with published v0.1 results.
- Provides source install flow, release installer, README demos, and launch announcement drafts.
